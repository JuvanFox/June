# June

June is a sophisticated personal intelligence project that brings genuine long-term memory, real-time screen awareness, and full system control together into an articulate, British-cadenced assistant.

## Features

- **Long-Term Memory:** Powered by an embedded PGlite instance for persistent memory database.
- **Visual Intelligence:** Real-time visual perception of your active workstation screen.
- **Workstation Control:** Direct execution of terminal commands and VS Code management.
- **Agent Orchestration:** Ability to deploy autonomous sub-agents for specialized tasks.

## Tech Stack

- **Framework:** React, TypeScript, Vite
- **Memory Database:** @electric-sql/pglite
- **AI Models:** Google GenAI (Gemini)
- **3D Rendering:** Three.js

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
