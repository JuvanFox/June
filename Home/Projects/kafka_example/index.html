Kafka Project Interface

This page demonstrates the data flow for the Kafka project.

Project Components

  • Node Modules (dependencies installed)
  • Docker Compose (Kafka initialisation)
  • Index.js (main application logic)

Data Flow

  1. Start Kafka cluster using Docker Compose
  2. Index.js connects to Kafka
  3. Producer sends messages to Kafka topic
  4. Consumer reads messages from Kafka topic
